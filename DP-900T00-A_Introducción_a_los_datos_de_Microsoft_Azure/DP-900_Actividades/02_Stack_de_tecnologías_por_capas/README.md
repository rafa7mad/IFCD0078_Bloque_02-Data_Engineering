# Actividad 2 - Stack de tecnologías por capas

## Instrucciones

Crear una infografía por cada capa del modelo de 7 capas en la cual se muestren:
- Tecnologías Open Source que se utilizan en esa capa
- Tecnologías de pago que mas se utilizan en esa capa
- Servicios de Azure y o Microsoft que suelen utilizarse en esa capa.

Nota: Excluir tecnologías de AWS y GCP
